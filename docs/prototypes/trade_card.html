Trade Card — component reference

Eight cards across the six-state FSM. All 14 owner-specified fields render on every card. Contract TradeCard/v0.2.0 · PLAYBOOK_v2.1.1 · design-only, not wired.

State machine (6 states)

T0 init → DETECTED
T1 attach thesis → FORMING
T2 preconds met → READY
T3 trigger fires → TRIGGERED
T4 decay / stale → FORMING
T5 gate active → BLOCKED
T6 gate clears → prev
T7 invalidation hit → BLOCKED
T8 ranker drops → (removed)
T9 terminal degrade → EXPIRED
T10 earnings blackout → BLOCKED
DETECTED FORMING READY TRIGGERED BLOCKED (branch) EXPIRED (terminal)
Field role tags · CTX context signal · THESIS setup hypothesis · SIDE conditional side · GATE READY / BLOCKED gate · FIRE drives TRIGGERED · RISK R implication (zone D) · DECAY drives READY→FORMING · META freshness/derived · STATE FSM state (zone A).  Invariant: current_structure_bias and setup_hypothesis.direction are independent (I-1).
